# Changelog

## 1.2.4+124

- Исправлена несовместимая с Dart форма многострочного регулярного выражения,
  из-за которой preflight-тест счётчиков Windows завершался с `Invalid group`.

## 1.2.3+123

- Исправлены постоянно нулевые счётчики загрузки и отдачи в Windows.
- Если служебный канал `awg show` недоступен обычному пользователю, приложение
  автоматически читает накопленные байты напрямую у активного WARP-адаптера.
- Ошибка телеметрии остаётся полностью изолированной от работающего VPN-туннеля.

## 1.2.2+122

- Первая установка Wintun на Windows теперь может находиться в
  `START_PENDING` до 60 секунд: приложение больше не удаляет службу через
  прежние 15 секунд, пока Windows ещё создаёт и привязывает адаптер.
- Ошибка чтения необязательной статистики `awg show` больше не переводит
  работающую службу в состояние ошибки и не создаёт ложное отключение.
- Заменены фотография Toasty-персонажа и сопровождающий MP3 пользователя.

## 1.2.1+121

- Android-селектор использует полный список установленных пакетов вместо
  списка только тех Activity, у которых есть иконка запуска.
- Добавлено Android-разрешение `QUERY_ALL_PACKAGES`, необходимое для полного
  списка в распространяемой напрямую APK-сборке.
- Windows runtime обновлён до официального AmneziaWG 2.0.0: он сохраняет
  поддержку AWG 1.5 и содержит более новое Wintun-ядро для актуальных Windows 11.
- Диагностика установленной 1.2.0 подтвердила: Setup и ASCII-путь работают,
  а AmneziaWG 1.0.2 завершался при создании сетевого адаптера с кодом 2.

## 1.2.0+120

- Windows artifact переведён с portable ZIP на установщик Pokolenie WARP.
- Приложение и встроенное AWG 1.5 ядро устанавливаются в защищённый
  `Program Files`; отдельный интерфейс AmneziaWG не устанавливается.
- Исправлен `SERVICE_EXIT_CODE 2` при запуске из пути с кириллицей.
- Конфиг службы и приватный ключ перенесены в ASCII-путь
  `ProgramData/PokolenieWARP/<SID>/runtime` с закрытым ACL пользователя и
  LocalSystem; кириллица в имени Windows-пользователя больше не влияет на запуск.
- Setup удаляет старую зависшую службу при установке и удалении приложения.
- Portable-запуск системного ядра из пользовательской папки заблокирован.
- Возвращены фирменная Windows-иконка и заголовок `Pokolenie WARP`.
- Windows CI повторно проверяет подготовленный host и наличие Setup artifact.
- Android split tunnelling получил нативный список установленных приложений с
  названиями, иконками, поиском и выбором; ручной ввод package ID удалён.

## 1.1.6+116

- Windows runtime переведён с AWG 2.0.2 на официальный AmneziaWG 1.0.2,
  соответствующий legacy/AWG 1.5 CPS-профилям генератора и стартовой базы.
- Проверка состояния службы и доступности интерфейса выполняется каждую секунду;
  UI больше не остаётся зелёным после исчезновения tunnel service.

## 1.1.5+115

- Обычное подключение больше не отключает туннель и не удаляет профиль при
  сбое фонового контрольного HTTPS-запроса.
- Удаление нерабочего профиля осталось только в явных операциях «Проверить» и
  «Проверить все последовательно».
- Windows-проверка использует Cloudflare WARP trace по адресу `1.1.1.1`,
  Cloudflare по имени и Google 204 вместо одной точки отказа.

## 1.1.4+114

- Исправлена передача пути к `.conf` через PowerShell `Start-Process`: пробелы
  и кириллица больше не разбивают путь на несколько аргументов.
- Добавлен тест Windows command line quoting, включая кавычки и завершающие
  обратные слэши.

## 1.1.3+113

- Исправлен Windows CI: удалён несуществующий URL `master/LICENSE`, который
  возвращал 404 уже после успешной сборки и распаковки AmneziaWG runtime.
- Текст MIT-лицензии хранится в исходниках и копируется в Windows artifact без
  дополнительного сетевого запроса.

## 1.1.2+112

- Официальное подписанное AmneziaWG x64 ядро теперь распаковывается внутрь
  Windows ZIP на этапе CI; отдельный AmneziaWG-клиент устанавливать не нужно.
- Pokolenie WARP запускает только службу выбранного туннеля, без второго окна,
  ярлыка, tray-менеджера и автозапуска AmneziaWG.
- Сборка прерывается, если подпись MSI невалидна или в runtime отсутствуют
  `amneziawg.exe`/`awg.exe`.

## 1.1.1+111

- Исправлена остановка Flutter analyzer в Windows core: PowerShell `$p` теперь
  находится в raw-строке и не интерпретируется как Dart identifier.
- Добавлена source-проверка безопасного экранирования UAC-команды.

## 1.1.0+110

- Добавлен настоящий Windows 10/11 x64 core поверх официальной службы
  AmneziaWG for Windows.
- Реализованы UAC-запуск и удаление tunnel service, проверка HTTPS, состояние
  службы и чтение нативной статистики через `awg`.
- Добавлена Windows CI-сборка ZIP.
- App-level split tunnelling в Windows явно заблокирован до отдельной
  интеграции WFP-драйвера; Android split tunnelling не изменён.

## 1.0.2+102

- Добавлены три проверенных стартовых профиля: WARP_STR5118,
  WARP_STR8605 и WARP_STR4470.
- Стартовые профили добавляются во внутреннюю базу только один раз. Если
  проверка или пользователь удалит профиль, он не появится снова после перезапуска.

## 1.0.1+101

- Исправлен импорт Portal WG/AmneziaWG конфигов с `Address` без CIDR-маски:
  IPv4 автоматически получает `/32`, IPv6 — `/128`.
- Убран Android MIME-фильтр, из-за которого `.conf` отображались серыми и не
  выбирались в системном проводнике.
- Та же нормализация применяется к профилю, полученному автогенератором, поэтому
  он сразу добавляется во внутреннюю базу.

## 1.0.0+100

- Полностью удалены VLESS и остальные прокси-протоколы, sing-box, каталоги и
  workflow обновления публичных ключей.
- Автогенератор сохраняет один WARP/AWG профиль сразу во внутреннюю базу.
- При запуске больше нет запроса VPN permission и фонового теста профилей.
- Проверка WARP поднимает реальный AWG-туннель и подтверждает HTTPS через него.
- Массовые проверки выполняются последовательно; временная системная ошибка
  останавливает очередь, а не удаляет весь список.
- Сохранено раздельное туннелирование Android и исправлены нативные счётчики.
- Возвращён Toasty-эффект: прозрачное лицо и звук после запуска VPN.
- Версия исходников и Android artifact переименованы в Pokolenie WARP 1.0.
