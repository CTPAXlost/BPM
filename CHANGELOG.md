# История изменений

## 0.9.1

- Удалён ложноположительный профильный ping: все протоколы проверяются реальным временным Android VPN.
- Успех требует HTTPS через VPN-сеть; для надёжности используются два независимых адреса.
- Массовая проверка стала строго последовательной, поскольку Android допускает одного владельца VPN.
- Добавлен генератор WARP, используемый Portal WG: `warp-gen1.vercel.app`.
- Исправлен импорт WARP/AWG с `Key=Value` без пробелов и добавлены расширения `.wg`/`.awg`.
- Версия повышена до `0.9.1+91`.

## 0.9.0

- Добавлена автоматическая регистрация Cloudflare WARP с локальной генерацией ключей.
- Добавлен пул endpoint-вариантов с ротацией адресов и портов Cloudflare.
- WARP теперь получает реальную HTTPS-проверку через временный AmneziaWG-туннель.
- Массовая WARP-проверка выполняется последовательно и использует общий карантин/автоудаление.
- Split tunneling работает в режимах include/exclude для sing-box и AmneziaWG.
- Android ABI ограничен `arm64-v8a`, нативные библиотеки упаковываются сжато.
- Удалён несовместимый с AGP 8.1+ параметр `enableUncompressedNativeLibs`; упаковкой управляет `jniLibs.useLegacyPackaging`.
- Версия повышена до `0.9.0+90`.

## 0.8.1

- Исправлен Android GitHub Actions: `flutter create` закономерно создаёт `.dart_tool`, и повторная проверка сгенерированного проекта больше не принимает эту рабочую папку за мусор в исходном архиве.
- Чистый исходник по-прежнему проверяется строго: `.dart_tool`, `build`, `.gradle`, `dist` и кэши запрещены до начала генерации.
- Режим `--allow-generated` используется ровно один раз — только после генерации Android host project.
- Добавлены регрессионные тесты порядка и режима проверки.
- Версия повышена до `0.8.1+81`.

# Журнал изменений

## 0.8.0

- Проект полностью переведён на Android-only.
- Удалены desktop/Windows-код, workflow, установщик, нативные файлы и зависимости.
- Полностью разделены URL Test и подключение к VPN.
- URL Test больше не вызывает разрешение Android VPN, `start()` или WARP/AWG.
- Добавлены отдельные экраны серверов и WARP в мобильной навигации.
- Добавлен массовый URL Test с настраиваемой параллельностью 1–4.
- Добавлена защита от массового удаления при отсутствии обычного интернета.
- Автоудаление выполняется только после настраиваемого числа подтверждённых провалов.
- Добавлен карантин удалённых профилей на 6 часов — 7 дней.
- Автообновление каталога сохраняет последний непустой набор каждого протокола.
- WARP импортируется ровно по одному конфигу с каждого поддерживаемого сайта или из файла.
- Для WARP убран фиктивный пинг: до подключения проверяется только структура конфига.
- Все WARP/WireGuard-конфиги направляются в нативное AmneziaWG Android-ядро.
- Удалены недоделанные игровые, split-tunnel и desktop-функции.
- GitHub Actions оставлен только для Android arm64 APK.
- Версия повышена до `0.8.1+81`.
