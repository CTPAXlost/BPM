# Безопасность

## VPN-разрешение

Разрешение Android VPN запрашивается при явном подключении и при первом URL Test. Проверка временно поднимает настоящий туннель, подтверждает HTTPS через связанную VPN-сеть и сразу его выключает.

## Каталог

Пользовательские источники принимаются только по HTTPS. Обновление не заменяет сохранённый рабочий каталог пустым ответом. Перед автоматическим удалением профилей приложение проверяет наличие обычного интернета.

## Генерация WARP

По явному нажатию приложение отправляет запрос одному из трёх HTTPS-зеркал открытого WARP Configuration Generator. Зеркало возвращает один AWG 1.5 конфиг; после успешного ответа действует локальный часовой лимит. Генерация выполняется на стороне зеркала, поэтому оператор зеркала технически может видеть созданный PrivateKey. Для максимальной приватности следует развернуть собственный экземпляр генератора и заменить список зеркал.

## Секреты

PrivateKey из WARP-конфигов хранится локально через SharedPreferences вместе с остальными импортированными профилями. Не публикуйте экспортированное хранилище и логи, содержащие полные конфигурации.

## Сборка

GitHub workflow скачивает официальный исходный модуль AmneziaWG Android по закреплённому тегу. Flutter Analyzer и тесты обязательны и не маскируются через `continue-on-error`.
