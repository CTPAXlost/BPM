# Безопасность

## VPN-разрешение

Разрешение Android VPN запрашивается только после явного нажатия **«Подключить»**. URL Test и проверка структуры WARP-конфига не запрашивают это разрешение и не запускают туннель.

## Каталог

Пользовательские источники принимаются только по HTTPS. Обновление не заменяет сохранённый рабочий каталог пустым ответом. Перед автоматическим удалением профилей приложение проверяет наличие обычного интернета.

## WARP WebView

Встроенное окно WARP открывается только по действию пользователя и разрешает два адреса: `https://warpgen.net/` и `https://warp-gen.github.io/`. Импортируется один полученный WireGuard/AmneziaWG-конфиг. Приложение не подключает его автоматически.

## Секреты

PrivateKey из WARP-конфигов хранится локально через SharedPreferences вместе с остальными импортированными профилями. Не публикуйте экспортированное хранилище и логи, содержащие полные конфигурации.

## Сборка

GitHub workflow скачивает официальный исходный модуль AmneziaWG Android по закреплённому тегу. Flutter Analyzer и тесты обязательны и не маскируются через `continue-on-error`.
