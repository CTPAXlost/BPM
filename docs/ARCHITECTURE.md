# Pokolenie WARP 1.0

The application intentionally accepts only WireGuard and AmneziaWG quick
configs. VLESS, VMess, Trojan, Shadowsocks, subscriptions, public catalogs and
the sing-box runtime are not part of this product.

## Runtime flow

1. Startup loads only locally stored, structurally valid WARP profiles. It does
   not request Android VPN permission and does not test anything automatically.
2. If the list is empty and automatic generation is enabled, one config is
   requested from the generator mirrors and stored directly in app storage.
3. Connect uses the official AmneziaWG Android backend generated by
   `tools/prepare_android.py`.
4. Test raises a temporary AWG tunnel, binds an HTTPS probe to the Android VPN
   network, then releases the tunnel. Tests are sequential to avoid VpnService
   races. A definitive failure may remove the profile.
5. IncludedApplications or ExcludedApplications are injected into the native
   config for Android split tunnelling.

Traffic counters are read from the native backend once per second. The Toasty
overlay and sound run only after the native tunnel start succeeds.
