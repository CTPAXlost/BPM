# Pokolenie WARP 1.0

Чистый Android-клиент WARP/WireGuard/AmneziaWG. В проекте больше нет VLESS,
VMess, Trojan, Shadowsocks, подписок, GitHub-каталогов и sing-box.

## Что работает

- автоматическое создание одного AWG 1.5 профиля, который сохраняется прямо в
  приложении без файла в памяти телефона;
- три проверенных стартовых профиля WARP_STR5118, WARP_STR8605 и WARP_STR4470,
  которые добавляются в базу один раз и затем управляются как обычные профили;
- ручной импорт `.conf` как резервный способ;
- нативное подключение через официальный AmneziaWG Android backend;
- проверка не «пингом порта», а временным туннелем и HTTPS-запросом через VPN;
- строго последовательная массовая проверка без одновременных `VpnService`;
- автоматическое удаление профиля только после окончательного провала проверки;
- Android split tunnelling через IncludedApplications/ExcludedApplications;
- нативные счётчики принятого/отправленного трафика;
- две визуальные темы;
- прозрачный Toasty-персонаж и звук после успешного запуска туннеля.

При старте приложение не просит Android VPN permission и не запускает проверки.
Разрешение нужно только для явного подключения или проверки, потому что честная
проверка сама является кратковременным VPN-соединением.

## Сборка

Запусти GitHub Actions workflow `Build Pokolenie WARP Android`. Он получает
официальный `amneziawg-android` 2.0.1, создаёт Android host, применяет
`tools/prepare_android.py`, выполняет analyzer/tests и выпускает arm64 APK.

Статус нативных Windows/iOS портов и обязательные системные компоненты описаны в
`docs/NATIVE_PORTS.md`.

Автогенерация использует публичный API открытого проекта
`HereIamGosu/amnezia-config-gen`; старые зеркала с обязательной CAPTCHA не
используются, поскольку они не могут работать в полностью автоматическом режиме.
