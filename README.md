# Поколение VPN 0.9.5

## Стабильная проверка, WARP-генератор и две темы

Android workflow теперь различает чистый исходный архив и служебные каталоги, которые Flutter создаёт уже во время сборки.

Android-клиент с автообновляемым каталогом VPN-конфигураций, отдельным разделом WARP/AmneziaWG, быстрым пингом списков и проверкой реального трафика при подключении.

## Что входит в Android-версию

- проект оставлен только для Android;
- удалены ПК-сборка, установщик, desktop-зависимости и незавершённые функции;
- массовая проверка обычных серверов использует быстрый нативный pingProfile без Android VPN;
- подключение выполняется только отдельной кнопкой;
- проверки запускаются только вручную: для одного ключа или текущей вкладки;
- обычные серверы проверяются четырьмя ограниченными параллельными работниками, WARP — строго последовательно;
- профиль удаляется после одного подтверждённого ручного тайм-аута при доступном базовом интернете;
- перед проверкой контролируется обычный интернет, поэтому временный обрыв не удаляет каталог;
- удалённый профиль помещается в карантин и не возвращается сразу после автообновления;
- в APK включены два проверенных пользователем профиля WARP STR; третий нерабочий удалён;
- генератор создаёт один новый AWG 1.5 конфиг в час через открытые резервируемые зеркала;
- статистика WARP берётся из нативных счётчиков AmneziaWG;
- повторный запуск проверки заблокирован и в интерфейсе, и в VPN-ядре;
- доступны темы «Кошмар» и «Симбиоз», возвращён фирменный щит;
- недоступные WARP и VLESS-профили получают счётчик провалов, удаляются и помещаются в карантин;
- split tunneling по Android package ID применяется и к sing-box, и к WARP/AmneziaWG;
- обычные протоколы обслуживает `singbox_mm`, WARP/AmneziaWG — нативный модуль AmneziaWG Android.
- релиз собирается только для `arm64-v8a`, нативные библиотеки сжимаются, а CI отклоняет APK больше 120 МиБ.

## Логика проверки

### Обычные VPN-профили

Для VLESS/VMess/Trojan/SS/Hysteria/TUIC список использует встроенный `pingProfile`: DNS, сокет и TLS/Reality проверяются без запроса разрешения Android VPN. Четыре проверки могут идти параллельно. Это проверка доступности сервера, а не speedtest и не обещание прохождения любого сайта.

WARP нельзя честно проверить таким способом, поэтому он по-прежнему временно поднимает настоящий AWG-туннель и требует HTTPS-ответ через связанную Android VPN-сеть. Два коротких контрольных адреса проверяются последовательно, успех одного достаточен; максимальное ожидание одного прохода уменьшено.

### Подключённый VPN

После явного нажатия **«Подключить»** выполняется та же HTTPS-проверка, привязанная к VPN-сети, для sing-box и WARP/AmneziaWG.

### Автоматическое удаление

Профиль удаляется после подтверждённого ручного провала быстрой проверки либо WARP URL Test и помещается в карантин. Отсутствие базового интернета или сбой самого механизма проверки не считаются подтверждённым провалом. После обновления каталога тесты автоматически не запускаются.

## WARP

На вкладке **WARP** доступны:

1. два встроенных профиля WARP STR;
2. реальная последовательная проверка всего WARP-пула;
3. импорт готового файла через системный Android-проводник без ненадёжного фильтра MIME/расширения;
4. генерация одного AWG 1.5 профиля с часовым лимитом;
5. нормализация `Address` без CIDR (`/32` для IPv4 и `/128` для IPv6).

Кнопка **«Проверить все WARP»** реально проверяет передачу HTTPS через каждый endpoint.

## Сборка APK через GitHub

1. Загрузить содержимое проекта в корень репозитория вместе с `.github`.
2. Открыть **Actions → Build Pokolenie VPN Android**.
3. Нажать **Run workflow**.
4. После успешной сборки скачать artifact **Pokolenie-VPN-Android**.

Workflow выполняет:

- статическую проверку исходников;
- Python-регрессии;
- сборку и проверку каталога;
- `flutter analyze --fatal-infos --fatal-warnings`;
- `flutter test`;
- генерацию Android host-проекта;
- подключение официального AmneziaWG Android core;
- повторный анализ и тесты;
- сборку arm64 APK и проверку нативных библиотек.

## Ограничения

Проверка подтверждает HTTPS через туннель, но отдельный сайт всё равно может блокировать конкретный IP. Отклонённый профиль удаляется только после настраиваемого числа повторных провалов, чтобы краткий сетевой сбой не уничтожил каталог.
