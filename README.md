# Поколение VPN 0.9.0

## Автоматический WARP и рабочая проверка 0.9.0

Android workflow теперь различает чистый исходный архив и служебные каталоги, которые Flutter создаёт уже во время сборки.

Android-клиент с автообновляемым каталогом VPN-конфигураций, отдельным разделом WARP/AmneziaWG и раздельными действиями **«URL Test»** и **«Подключить»**.

## Что входит в Android-версию

- проект оставлен только для Android;
- удалены ПК-сборка, установщик, desktop-зависимости и незавершённые функции;
- URL Test больше не запрашивает разрешение Android VPN и не поднимает системный туннель;
- подключение выполняется только отдельной кнопкой;
- массовый URL Test работает с ограниченным числом параллельных проверок;
- недоступный профиль удаляется только после нескольких подтверждённых провалов;
- перед проверкой контролируется обычный интернет, поэтому временный обрыв не удаляет каталог;
- удалённый профиль помещается в карантин и не возвращается сразу после автообновления;
- WARP регистрируется автоматически через Cloudflare, а ключевая пара создаётся локально на Android;
- один WARP-аккаунт разворачивается в пул endpoint-вариантов, которые проверяются реальным HTTPS через временный туннель;
- недоступные WARP и VLESS-профили получают счётчик провалов, удаляются и помещаются в карантин;
- split tunneling по Android package ID применяется и к sing-box, и к WARP/AmneziaWG;
- обычные протоколы обслуживает `singbox_mm`, WARP/AmneziaWG — нативный модуль AmneziaWG Android.
- релиз собирается только для `arm64-v8a`, нативные библиотеки сжимаются, а CI отклоняет APK больше 120 МиБ.

## Логика проверки

### Обычные VPN-профили

Для VLESS/VMess/Trojan/SS/Hysteria/TUIC `URL Test` использует профильную проверку `singbox_mm` без системного VPN. Для WARP проверка последовательно поднимает временный AmneziaWG-туннель, выполняет HTTPS-запрос через VPN-сеть и сразу выключает его.

### Подключённый VPN

После явного нажатия **«Подключить»** приложение отдельно проверяет состояние подключённой VPN-сети. Для sing-box используется статус Android `networkValidated`; для WARP/AmneziaWG выполняется HTTPS-проверка, привязанная к VPN-сети.

### Автоматическое удаление

По умолчанию профиль удаляется после трёх подтверждённых провалов URL Test. Порог, карантин и автоматическое удаление настраиваются. Ошибка разрешения VPN, отсутствие базового интернета или сбой самого механизма проверки не считаются подтверждённым провалом.

## WARP

На вкладке **WARP** доступны:

1. автоматическая регистрация и создание endpoint-пула;
2. реальная последовательная проверка всего WARP-пула;
3. резервный импорт с WarpGen.net;
4. импорт одного `.conf` или `.txt`.

Приватный ключ автоматического WARP создаётся классом `KeyPair` официального Android-ядра AmneziaWG и не передаётся стороннему генератору. Кнопка **«Проверить все WARP»** реально проверяет передачу HTTPS через каждый endpoint.

## Сборка APK через GitHub

1. Загрузить содержимое проекта в корень репозитория вместе с `.github`.
2. Открыть **Actions → Build Pokolenie VPN Android**.
3. Нажать **Run workflow**.
4. После успешной сборки скачать artifact **Pokolenie-VPN-Android**.

Workflow выполняет:

- статическую проверку исходников;
- Python-регрессии;
- сборку и проверку каталога;
- `flutter analyze --fatal-infos --fatal-warnings`;
- `flutter test`;
- генерацию Android host-проекта;
- подключение официального AmneziaWG Android core;
- повторный анализ и тесты;
- сборку arm64 APK и проверку нативных библиотек.

## Ограничения

URL Test без системного VPN предназначен для предварительного отбора профилей. Окончательно работу пользовательского трафика можно подтвердить только после подключения и проверки нужных приложений.
